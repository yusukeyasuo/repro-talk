# 卒業制作 発表スライド アウトライン（6分）

- 対象: AI-Driven School 卒業制作 発表会
- 持ち時間: **6分**（= 360秒）
- 聞き手: チームのメンバー。**自分の仕事の中身を知らない**、職種も立場もバラバラ
- 元ネタ: [`docs/zukai/index.html`](zukai/index.html)（提出物の図解 / https://repro-talk.surge.sh ）
- 本番: https://repro-talk.vercel.app

---

## 設計方針（先に決めたこと）

- **図解をそのまま喋らない。** 図解は「読ませて全部伝える」媒体、発表は「聞かせて1つ残す」媒体。
  面倒7つ・苦戦6項目・画面7つを全部話すと1項目15秒未満になり、読み上げになる。**話すのは各カテゴリ2〜3個に絞り、残りは「図解に全部あります」で送る。**
- **持ち帰ってほしい1文を先に固定する。**
  → 「**続かない原因は意志ではなく小さな面倒だった。だから面倒のほうを、自分で作った道具で消した。**」
  全スライドはこの1文の補強に使う。補強にならないスライドは切る。
- **英語学習アプリの話に見えて、実は「詰まりを道具で消す」話。** 聞き手は英語学習者ではない。
  英語の詳細（発音記号7種の中身など）は深追いせず、**誰の仕事にも当てはまる形**に翻訳して話す。
- **前提から積む。** 自己紹介 → 仕事 → 困りごと → 学習法 → 本当の問題 → 作ったもの、の順を崩さない。
  「リプロダクション」という単語を説明なしに出さない。

## スライドごとの中身

### 1. タイトル（10秒）
- `repro-talk` — 英語学習を「始められる」そして「続けられる」自分専用アプリ
- サブ: 卒業制作『自分の武器を作る』/ 名前 / 所属
- **話す**: 「英語学習のアプリを作りました。ただ、今日話したいのは英語の話ではなく、"やると決めたのに始められない・続かない"をどう潰したかの話です」

### 2. 自己紹介 / どんな仕事をしているか（30秒）

**スライドに載せる**
- **安尾** / **エンジニアリングマネージャー**
- **社内向けのシステム・基盤**を作るチームのマネジメント
- 業務で**自分でコードを書くことはほぼ無い**
- 仕事道具は**PCとスマホだけ**。紙のノートもペンも使わない

**話す**
> 「安尾です。社内で使うシステムや基盤を作るチームのマネージャーをしています。
> **普段、自分で手を動かしてコードを書くことはほとんどありません。**
> 仕事道具はPCとスマホだけで、紙のノートもペンも使いません。
> ——この2つは、あとで効いてきます。」

**この1枚は伏線を2本張るためにある。説明としては短くていい**
- 伏線A「コードを書かない」→ 8枚目のデモと13枚目で回収（**書かない立場の人間が、AIを使って作り切った**）
- 伏線B「紙もペンも無い」→ 5枚目で回収（**教わったやり方は紙とカラーペン7色だった**）
- ⚠ 逆に言うと、この2つ以外は削ってよい。経歴や実績を語る枚ではない

### 3. 何に困っていたか（30秒）

**スライドに載せる**
- 海外チームとの**定例ミーティング**、**Slack・ドキュメント**でのやりとりがある
- 読み書きは困らない。**翻訳ツールを使えば足りる**
- **会話は違う。リアルタイムなので、翻訳ツールを挟めない**
- 言いたいことが言えない / 言っても伝わらない / 言われたことが理解できない /
  **聞き返しても、やっぱり理解できない**
- **本当は海外メンバーと1on1をしたい。言語を理由にできていない**
- 目指しているのは **海外メンバーを含むチームを率いること**。英語はその手段

**話す**
> 「海外チームとの定例や、Slackでのやりとりがあります。
> **読み書きは困っていません。翻訳ツールを使えば足りるので。**
> 問題は会話です。**会話はリアルタイムなので、翻訳ツールを挟む時間がない。**
> 言いたいことが言えない。言っても伝わらない。言われたことが理解できない。
> **聞き返しても、やっぱり理解できない。**
> 極めつけは、**海外メンバーと1on1が組めていないこと**です。
> マネージャーとして本来やるべきことが、言語を理由にできていない。
> 自分がやりたいのは海外メンバーを含むチームを率いることなので、ここは避けて通れませんでした。」

**⚠ 「翻訳ツールで足りる／会話には挟めない」は絶対に落とさない**
- 聞き手はAI-Driven Schoolのクラス。**「英語こそAIが解決するのでは」と当然思う**
- この2行が、その問いへの先回りの答えになっている。ここを飛ばすと発表全体の前提が崩れる

**⚠ 「聞き返しても、やっぱり理解できない」も落とさない**
- 「英語が苦手」という一般論を、聞き手が想像できる具体に落としている唯一の行

### 4. これまでの学習と、出会った学習法（45秒）

**前半: これまで（15秒。ここは速く流す）**
- オンライン英会話や独学 → **続かなかった**
- **PROGRIT のコーチングでは、伸びた（A2 → B1）**
- ただし**題材が業務に特化していなかった**ため、**業務での会話力には効かなかった**
- **話す**: 「勉強していなかったわけではありません。**やって、伸びてもいます。**それでも、仕事の会話は変わりませんでした」

**後半: PROGRITを終えたあとに見つけた学習法（30秒）**
- 必要なのは2つだけ
  - **① 完成された英語を「100」のまま受け取る**（音声を1文再生 → 止める → 同じように言う）
  - **② 「0」から自分で作り出す**（お題に沿って独り言）
- 図: 100 ←→ 0 の対比（図解のヒーロー部分を流用）
- **話す**: 「これまで試したどの教材より説得力があった。これをやれば伸びる、と素直に思えました」
- 注意: 専門用語（リプロダクション）は**この場で定義してから**使う

**⚠ 図解との食い違い**
- 図解は出所を「英語学習の**セルフコーチングで教わった**」と書いている
- 実際は**PROGRITを終えたあとに自分で見つけた**方法。発表は後者で話すほうが3枚目・9枚目と繋がる
- 図解側の文言も揃えるかどうかは要判断（揃えなくても発表は成立する）

**⚠ PROGRITを「失敗」として話さない**
- A2→B1 は事実として伸びている。**否定すると聞き手に「他責の人」に見える**
- 言うべきは「効かなかった」ではなく「**業務の題材ではなかったので、業務の会話には届かなかった**」

### 5. 転機: 「続かない」ではなく「始められない」だった（40秒） ★山場
- **これをやれば伸びる、と思えたのに、始めることすらできなかった**
- 教わったやり方は **紙に行間を空けて、カラーペン7色で音の記号を書き込む**
  - PCとスマホでしか作業しない自分に、紙の習慣もカラーペンも無い
- 面倒はそこだけではなかった（並べて見せる）
  - 自分に合った動画を探す / 練習する区間を選ぶ / 同じ30秒を何度も再生する / 自分の声を録る / 覚えたフレーズを書き留める / 分からない音をChatGPTにコピペする
- **結論**: 続かないのは意志の弱さだと思っていた。**正体は、この小さな面倒の積み重ねだった**
- **話す**: 「だから、意志で乗り越えるのをやめました。**面倒のほうを消す**ことにしました」
- ※ ここが発表全体の軸。ここだけは絶対に削らない・急がない

### 6. 作ったもの: repro-talk（20秒）
- 一枚で全体像（ホーム画面のスクショ）
- **紙とペンとChatGPTの往復を、1つのアプリに畳み込んだ**
- 技術は1行だけ: Next.js 16 / Supabase / Claude API（**深追いしない**。聞き手の職種はバラバラ）

### 7. 3本の柱 + 自分で足した1本（40秒）
- **100 リプロダクション** — 受け取る（1文再生して止める / A-Bループ / 0.5倍速）
- **↔ フレーズ** — **繋ぐ**（①で覚えた型を②へ受け渡す。使えたら卒業）
- **0 独り言** — 作り出す（お題に沿って「1人電話」）
- **＋ 瞬間英作文** — 使ううちに見えた穴を、**教わった方法論の外から自分で足した**
  - 「100を受け取っても、0からは出てこない」→ 日本語で考えて詰まる部分だけ別に鍛える
- **話す**: 「真ん中の"繋ぐ"が肝です。覚えた表現が使われずに眠るのを防ぐ」
- ※ 「自分で1本足した」は**評価されるポイント**。作って終わりでなく、使って直した証拠として明示的に言う

### 8. デモ（50秒） ★見せ場
- 見せるのは **`/clips/[id]` 1画面だけ**。あちこち回らない
- 流れ:
  1. 左: 登録した区間を「1回再生して止める」→ 自動で止まる
  2. 右: スクリプトをドラッグ → 発音記号を付ける（**紙とカラーペンの代替がこれ**）
  3. 分からない表現を選択 → AIが意味と例文を返す（**ChatGPTへのコピペがこれ**）
- **話す**: 「5枚目で挙げた面倒が、この1画面で全部消えています」
- ⚠ **6分でライブデモは危険**（ネットワーク・ログイン・音声）。**画面録画 or 連続スクショ**を推奨。
  音を出すなら事前に会場で音量確認

### 9. 消した面倒 — 3つに絞る（45秒）
- 図解の7つのうち、**話すのは3つだけ**。残りは「他にもあります、図解に全部書きました」
- 推奨する3つ（他と話が重複せず、聞き手に一番伝わる順）:
  1. **紙とカラーペン → 画面上のドラッグ**（始められなかった最大の原因そのもの）
  2. **ChatGPTへの手動コピペ → アプリ内で完結**（AI活用として一番わかりやすい）
  3. **練習したい英文が動画に無い → 自分で書いた英文を貼ればクリップになる**
     （AIの声が1文ずつ読んで止まる。マーキングも録音も同じ画面で）
- 各面倒は **「面倒 → 解決後の画面」の対** で1行ずつ。文字は詰めない

**3つ目に「自作テキスト」を選んだ理由**
- 図解の原文が「**仕事で言えなかった一言ほど、YouTubeを探しても出てこない**」
- これは 3枚目（言えなかった一言）と 4枚目（**PROGRITは題材が業務特化でなかった**）**両方への回答**になっている
- **話す**: 「PROGRITで伸びても仕事の会話が変わらなかったのは、題材が仕事じゃなかったからでした。
  だから、**言えなかった一言をそのまま素材にできる**ようにしました」
- 「可視化」は 10枚目に移した（隣接する2枚で同じ画面を出さないため）

### 10. 工夫したこと（30秒）
- **手が止まる場所を、そのまま機能にした** — 探す/選ぶ/繰り返す/録る/残す を1操作に翻訳
- **AIをアプリに畳み込み、行き来をゼロにした**
  - 精度の作り込みも一言: LLMは数値位置が不安定なので **`quote＋出現回数` で復元**（技術の聞き手向けの一刺し）
- **「続く」を可視化した** — 面倒を消すだけでは続かない。連続日数・12週ヒートマップ・再現回数・独り言の合計時間を、常に目に入る場所に出した
  - **話す**: 「これが効きました。積み上がった記録が見えると、**途切れさせたくなくなる**。続けるためのモチベーションが自分の中に湧いて、気合いを入れなくても自然と毎日開くようになりました」
  - 面倒を消したことで**始められる**ようになり、可視化したことで**続けられる**ようになった（1枚目の宣言をここで回収する）

### 11. 苦戦したこと（25秒）
- 「動くはず」が動かない罠を1つずつ踏んだ、と総括して **具体例は1〜2個だけ**
- 推奨: **読み上げ（TTS）の全面作り直し**
  - ブラウザ標準の読み上げが無音で固着 → 延命を諦めてクラウドTTSへ全面移行
  - すると本番だけ保存が3段の罠（データ破損 / 権限 / 認証キーの形式）で止まった
  - **話す**: 「作り直す判断と、本番でしか出ない問題の切り分けに一番時間を使いました」
- 予備で持っておく（時間が余ったら）: iOS Safariの録音形式 / YouTubeの区間ループが素直に作れない
- ※ 技術の細部に入りすぎない。**「環境が現実を返してくる」**という一段上の話にまとめる

### 12. 使ってみてどうなったか（15秒）

**スライドに載せる（実データ。累計ではなく今週の値）**
- **連続 11日**（途切れていない）
- 今週: 独り言 **5分59秒** / リプロダクション **33回** / 瞬間英作文 **137回**
- **一番回っているのは、あとから自分で足した瞬間英作文**
- 独り言だけは、まだ習慣になっていない

**話す**
> 「11日、途切れていません。**一番使っているのは、作ってから足した瞬間英作文でした。**
> 逆に、独り言だけはまだ習慣になっていません。**次に面倒を消しにいくのはそこ**だと、もう分かっています。」

**⚠ ここで盛らない**
- 「累計」と言わない（11日以外は今週の値）
- 「ずっと続けています」と言わない（ヒートマップは直近3週ほど）
- **英語力が伸びたとは、まだ言わない**。測っていないなら「まだ測っていない」と言い切るほうが強い
- 弱く見えることを恐れて曖昧にすると、13枚目の「自分の武器は自分で作れる」まで軽くなる

### 13. 学び / クロージング（20秒）
- **自分の武器は、自分で作れる。**
- AI-Driven Rules の「自分の武器を自分で作れ」「1クリックを減らせ」
- いくつもの道具を行き来していた学習が、**自分で作った1つのアプリに収まった**。
  そこから1クリックずつ削るほど、迷いも中断も消えた
- **聞き手への持ち帰り**: 「続かないことがあるなら、意志の問題ではなく**面倒の問題**かもしれない。
  そして、その面倒は**自分で消せる**」

## 話さないと決めるもの（意識的に捨てる）

- 発音記号7種の中身（強勢・脱落・リンキング…）→ 画面に映すだけ。**説明しない**
- 素材レベル L1〜L4 の定義
- 面倒の残り4つ（区間の再生位置戻し / 独り言が止まる / 動画に無い英文 / フレーズが眠る のうち触れない分）
- 苦戦の残り（`getUserMedia` タイムアウト / 選択が消える / 一時停止の端末差）
- Supabase のスキーマ・RLS・デプロイ構成
- **YouTube音源はダウンロードしない・発音の自動採点はしない**という不採用判断
  → 質疑で聞かれたら答える。スライドには載せない

## 質疑で来そうなもの（手元メモ）

- 「どのくらいの期間で作った？」
- 「なぜ既存アプリ（シャドーイング系）を使わない？」→ **教わった学習法に忠実な道具が無かった**から。特に「止めて言う」と「0と100を繋ぐ」
- 「AIは何をしている？」→ 音の解析 / 表現の解説 / 独り言の英語化 / フレーズ抽出。全部ChatGPTへのコピペの内製化
- 「発音は採点してくれる？」→ **やらない判断をした**。精度が出ず、誤った採点は学習者を害するから
- 「他の人も使える？」→ 自分専用として作った。設計は個人利用前提
- 「英語は実際に伸びた？」→ **正直に答える**。個人の体験談であり成果の保証はしない、という前提は図解にも書いてある

## 実データから見えたこと（12枚目に直結）

**① 一番回っているのは、方法論の外から自分で足した「瞬間英作文」**
- 今週: 瞬間英作文 **137回** / リプロダクション **33回** / 独り言 **5分59秒**
- **話す価値がある**: 「作ってから気づいて足した機能が、いま一番使われています。
  **使ってみないと分からなかった**」

**⚠② 独り言は、目標に届いていない**
