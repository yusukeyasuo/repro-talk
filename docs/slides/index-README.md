# 発表スライド（6分・13枚）

卒業制作『自分の武器を作る』発表会用。単一の `index.html` と `shots/` だけで完結する。
構成の根拠・話す内容の詳細は [`docs/presentation-outline.md`](../presentation-outline.md) にある。

## 開き方

`index.html` をブラウザで直接開く（サーバー不要）。**`F` で全画面にしてから発表する。**

公開版: https://repro-talk-slides.surge.sh （図解 https://repro-talk.surge.sh とは別ドメイン）
**本番はローカルのファイルを開くほうが安全**（会場のネットワークに依存しない）。公開版は共有・保険用。

再デプロイ:

```sh
cd docs/slides
surge ./ repro-talk-slides.surge.sh
```

| キー | 動作 |
|---|---|
| `→` `←` `Space` | 次 / 前へ（画面クリックでも次へ） |
| `1`〜`9` | その番号のスライドへジャンプ |
| `F` | 全画面 |
| `S` | スピーカーノート（話す内容・注意点）を表示 |
| `T` | 6分カウントダウンの開始 / 一時停止 |
| `R` | タイマーをリセット |

右下のHUDは `残り時間 / この枚の持ち時間・想定とのズレ / 現在ページ`。
ズレが `+5s` を超えると琥珀、`+15s` を超えると赤になる。**リハはこれを見ながら回す。**

> ノートを出すと画面下部が隠れる。**リハ専用**で、本番は `S` をOFFにして映す。

## PDFにするには

ブラウザの印刷 → 用紙サイズ「1280 × 720 px」または横向き・余白なし → PDFで保存。
1枚1ページで出る（HUDとノートは印刷されない）。会場の環境が不安ならこれを保険に持つ。

## デモ（8枚目）

**実機でリアルタイムに行う。** 8枚目には静止画を1枚仕込んであるので、
転んだ場合はスライドのまま口頭で押し切る（切り替えに時間を使わない）。

事前チェック: ログイン済み / 音量 / ネットワーク / 通知OFF。

## 差し替えるとき

- 文言は `index.html` を直接編集する。各スライドは `<section class="slide" data-t="秒数">`。
  `data-t` がその枚の持ち時間で、HUDのズレ計算に使われる。合計は350秒（＋バッファ10秒）
- スピーカーノートは各 `<section>` 末尾の `<div class="notes">`
- 画像は `shots/`。`docs/zukai/shots/` からコピーしたもので、
  **ローカルにデモデータを入れて撮った実キャプチャ**。撮り直す場合も同じファイル名で差し替えればHTMLの変更は不要

## 数字について

12枚目の数値は**実データ**（連続11日 / 今週の独り言5分59秒 / リプロダクション33回 / 瞬間英作文137回）。
連続日数以外は**今週の値**なので、「累計」とは言わないこと。
